# Organização das entregas

O modelo `.github/ISSUE_TEMPLATE/entrega.yml` exige problema, área, contratos/dependências, aceite com evidência e revisão/rollback. Como a lista técnica não nomeia as seis áreas, foi preparada esta divisão para revisão da equipe:

1. Dados e fontes.
2. Rotas e clima.
3. Backend e segurança.
4. Interface e onboarding.
5. Relatórios e demonstração.
6. Operação e qualidade.

O quadro deve ter estado da entrega, área, responsável, dependências e PR. Não confundir “implementado” com “revisado/homologado”; uma dependência não é concluída por haver uma tela explicando a ausência.

Em 15/10/2026, a consulta/criação do GitHub Projects com a credencial disponível foi recusada pela API GraphQL com `INSUFFICIENT_SCOPES`. O quadro **não foi criado nem vinculado**. Não houve ampliação de acesso ou criação de token. A criação do Projects e a confirmação das seis áreas permanecem pendentes; o template de issue fica utilizável no repositório.
